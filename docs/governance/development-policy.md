# 开发策略入口

Fongap Labs 的共享开发治理由 [Action Worker](https://github.com/fongap-labs/action-worker/tree/main/docs) 维护。本文件作为中央契约测试的兼容入口，不重复实施细则。

- **Clean replacement rule**：当设计被替换时，必须 **remove the superseded path in the same change**。
- **Tier 1 is free API-token capacity; Tier 2 is static API Token reserve; no membership subscription or Tier 3 execution path remains**。
- **Project release numbering is not an engineering automation concern**：发布标识由人工管理。
- 项目详细要求见[产品策略](product-policy.md)、[质量策略](quality-policy.md)与[依赖策略](dependency-policy.md)。
