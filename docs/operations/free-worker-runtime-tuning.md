# Free Workers 流式稳定性配置

本页只列生产可选的非敏感运行参数。由 **Action Worker 现有部署变量链**向四个 Worker 分发；不得新建 Secret、改名现有变量、把私密节点配置写入仓库，也不得绕过发布门禁直接部署。以下为 **建议值，不表示生产已生效**。

| 变量 | 建议值 | 作用与限制 |
| --- | --- | --- |
| `AIG_HOT_PATH_GUARDS` | `true` | 减少热路径额外计算 |
| `AIG_REQUEST_ADMISSION` | `true` | 启用已有的请求保护与非必要 hedge 收敛，不改变兼容模型池耗尽时对外返回 503 的现有协议 |
| `AIG_STREAM_PASSTHROUGH` | `true` | 仅在无需改写物理模型名、或已有 Matrix 转换的条件下直通；不是强制所有流直通 |
| `AIG_COST_GUARDS` | `true` | 降低可选 D1 模型明细采样与 KV 亲和度写入；全局 usage 不抽样 |
| `AIG_STREAM_MAX_ATTEMPTS` | `4` | 每轮流式请求最多四次逻辑尝试；并非四次都一定执行 |
| `AIG_UPSTREAM_HEADER_TIMEOUT_MS` | `20000` | 基准头部等待 20 秒；大提示词的 size allowance 与阶段/总预算仍可能增减有效等待 |

## 迁移与回滚

1. 先确认仓库源码、`validate-merge` 和中心协议契约全部通过；这不是生产变更授权。
2. 对现有 Action Worker 发布变量清单作只读比对，保留明确配置的值和既有变量名称，只新增确实缺失的非敏感值。Secret 仍归原部署治理链管理。
3. 逐步在原有发布环境启用，按相同时间窗口记录请求成功率、首 token 耗时、1102、429、503、504、超时轮转、Worker CPU、平均请求体大小及 Token 吞吐。不得只用 Token 总量判断可靠性。
4. 若成功率下降、Code- 模型能力退化、工具调用丢失或 CPU 限额反而恶化，逐项设回先前值；所有开关支持显式 `false`，不修改节点凭据与协议配置。

**已在源码修复**：普通 SSE delta 无条件解析、重写场景重复解码、模型族重试等待丢失、跨协议流混用缓冲截止时间，以及原生大 JSON 重复序列化。

**未修改**：跨 env 的节点配置缓存。只按 env 对象引用缓存虽然可能造成重复解析，但无有效配置版本键时跨请求缓存凭据有热更新与安全风险。需要生产遥测证明收益并设计失效机制后单独优化。
