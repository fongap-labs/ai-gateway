# Free Workers 流式可靠性调参

本说明只列已有的非敏感运行变量，不直接修改生产环境。所有变量继续由现有 Action Worker 发布链管理；禁止新建或改名 Secret、绕过 CI、写入私有节点信息。

**原则：先验证代码修复，再基于实际数据调参。** 免费模型的首 Token 时间、429 限流、节点吞吐随时变化，不能把本次优化等同于统一降低请求等待时间或尝试次数。

| 现有变量 | 处理方式 | 主要风险 |
| --- | --- | --- |
| `AIG_HOT_PATH_GUARDS` | 比对当前配置，按实测 CPU 热点决定是否启用 | 需确认观测数据完整 |
| `AIG_COST_GUARDS` | 仅在确认可选存储写入影响 Free Workers 成本时试点 | 不得牺牲全局使用量结算 |
| `AIG_STREAM_PASSTHROUGH` | 仅对已验证语义等价的原生流执行灰度 | 不能丢工具调用、usage、流式错误 |
| `AIG_REQUEST_ADMISSION` | 保持当前部署值；独立验证准入与 hedge 策略 | 过早收紧会降低成功率和 Token 吞吐 |
| `AIG_STREAM_MAX_ATTEMPTS` | 不统一设置为 4，保留原生已验证的重试预算 | 免费节点不稳定，盲目减少候选可能恶化成功率 |
| `AIG_UPSTREAM_HEADER_TIMEOUT_MS` | 不统一设置为 20 秒；检查是否有显式覆盖，再与首输出预算一起评估 | 显式短超时可能提前断开正常的 Code 预填充请求 |

## 验收与回滚

1. 按 PR 当前 SHA 通过中央 CI、协议矩阵、大 JSON 与 SSE 回归；合并到 `main` 后也必须验证新 SHA。
2. 只读核对现有 Action Worker 参数和发布环境，**不新增 Secrets，不替换任何现有变量名**。
3. 对同一批模型和流式请求，在相同口径窗口比较成功率、429/503/504、首次输出延迟、工具调用完整率、Worker CPU、Token/日和平均每次成功所需物理派发次数。
4. 只逐项修改有实测收益的配置；一旦成功率或 Token 吞吐下降，恢复该项先前值。部署权限、生产凭据与 Canary 发布由既有发布门禁负责。

已实现的源码改动包括：减少普通 SSE 分片的无效解析、避免重复 UTF-8 解码、保守改写大 JSON 顶层 `model`、保留兼容模型族冷却时间、区分实时流与缓冲对象的截止时间。**私有中心超时但执行结果未知时不自动重复派发；保留对外 503 兼容性。**

未修改跨请求节点配置缓存。没有可信的配置版本与失效机制时，跨环境共享凭据缓存可能引入热更新和安全风险。
